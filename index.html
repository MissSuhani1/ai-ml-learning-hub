🧪 Python Diagnostic Test

Why this test? “Basic Python” means different things to different people. This test checks the skills that form a practical foundation for AI/ML.

Don't Google. If you don't know an answer, choose “I don't know”. The goal is to find your starting point, not to score high.

What counts as “ideal basic Python”?

Foundation level

By the end of this level, you should comfortably handle:

  • Variables, numbers, strings, booleans and type conversion
  • if/elif/else and for/while loops
  • Lists, tuples, dictionaries and sets
  • Functions, parameters and return values
  • Indexing, slicing and basic list comprehensions
  • Basic string/list/dictionary operations
  • Simple problem solving: digits, prime, palindrome, factorial, patterns
  • Reading errors and debugging simple programs
  • Basic file handling and a first understanding of OOP

Important: You do NOT need advanced OOP, decorators, generators, async programming or complex libraries before starting NumPy/ML.
